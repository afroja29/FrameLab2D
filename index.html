Download and run in MATLAB

DOWNLOAD MATLAB PACKAGE (.ZIP)Download main .m file
  1. Extract the ZIP.
  2. Open MATLAB and select the extracted FrameLab2D folder as Current Folder.
  3. Type FrameLab2D in the Command Window, or open and run START_FRAMELAB.m.
  4. Click LOAD RC DEMO, then RUN STATIC ANALYSIS.

The main file is self-contained. Keep its filename FrameLab2D.m. Desktop MATLAB is required. Python and OpenSees are not needed for the MATLAB GUI.

Methods and limits

Seven areas: frame analysis, sensor network, damage diagnosis, dynamics, sensor placement, P-Delta/reference buckling and exposure scenarios. Every response uses the active healthy or deteriorated stiffness. Exposure losses are assumptions. The live app supports up to 4 stories and 3 bays. The model omits yielding, cracking, bond slip and corrosion progression. Sensor scores and buckling factors use custom calculations around structural responses.
